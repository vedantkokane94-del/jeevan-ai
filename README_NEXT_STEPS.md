## 🆘 Having Issues?

### Issue: GitHub 403 Permission Denied
**Solution:** Create new repository
- Go to: https://github.com/new
- Name: jeevan-ai
- Visibility: Public
- Then: `git remote set-url origin [new-url] && git push -u origin main`

### Issue: Need SSH Instead
**Solution:** Generate SSH key
```powershell
ssh-keygen -t ed25519 -C "vedantkokane94@gmail.com"
git remote set-url origin git@github.com:vedantkokane94-del/jeevan-ai.git
git push -u origin main
```

### Issue: Frontend won't build
**Solution:** Check Next.js build
```powershell
cd apps/web
npm run build
```

### Issue: API connection fails
**Solution:** Verify environment variables in Vercel & Render dashboards
